# v33 白球新報・記事生成刷新
- 50報道テーマ × 見出し・導入10種 × 本文構成10種 = 5,000組合せ。直近記事と同じ構成を避ける。人手で5,000本の独立記事を執筆した方式ではない。
- 試合記事は確定スコア、イニング別得点、終了理由、投打成績、対戦校、MVP、試合ログを使用。サヨナラは終了理由で判定。監督・選手談話はゲーム内創作と明記。
- 部内、施設、予算、指導体制、スカウト、中学野球、全国、U-18、卒業生、記録、特集、大会展望等。週刊部員・疲労・負傷・成績・日程、登録選手から記事を追加。
- 一面、試合・大会、学校・部内、全国・進路、特集・記録の面別表示。全文リーダー、記録表、試合経過、年度・カテゴリ・全文検索。既存記事は維持。新記事は掲載時の数値を保存。コラムは号の日付と記事を使用。
- 保存上限600件は維持。容量不足時は従来の整理処理。全国記事・特集の旧ランダム生成は登録選手を基にする方式に変更したため、出現頻度・乱数消費は変わる。
- news-patterns.html で50の具体的な架空サンプルから全5,000構成を確認。
- test/news_v33.cjs は件数、ID、本文重複、スコア分類、決定性、構文を検証。ブラウザ実機での表示は未確認。
