# v30 UI・素材デザイン
ネイビー・深緑・真鍮色を軸に、育成画面と試合の中継風HUDを統一。ライト／ダークの既存選択を維持。
- ホーム: チーム力・人数・平均疲労・ケガと年度内48週の進捗を表示。
- 部員: 既存の選手ID・ユニフォーム対応の肖像を表示。検索（名前・背番号・守備位置等）と並べ替えを追加。一括練習設定は検索で表示中かつ設定可能な選手だけに適用。
- 選手詳細: 選手プロフィール・背番号・既存の公開能力情報。能力の公開条件は変えない。
- 試合: スコア・カウント・操作ボタン・字幕・リプレイの視認性を改善。既存v29操作と判定は維持。
- 64個のオリジナルSVG機能アイコン、6点のオリジナル背景イラスト、ロゴSVG、3サイズのホーム画面アイコンPNG。SVGスプライトと一覧を同梱。
- 素材ライブラリ ui-assets.html（その他→設定からリンク）。SVGはコード生成のベクターイラストで、実写・新規3D素材とは別。
- 900px以上はサイドメニュー、狭い画面は下部メニュー。既存セーブデータ構造・試合エンジン・育成計算は変更しない。
- 検証: node test/ui_v30.cjs。ブラウザ実表示・実機性能は別途検証が必要。
