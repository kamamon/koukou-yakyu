# v29 全領域改修
## 実装
- assets/player_deform_v29.json: MakeHuman CC0 元の骨ウェイトをゲーム用16制御関節と67追加変形ボーン（計83本）へ割り当てたデータ。body 13,380、uniform 2,674 頂点の照合レコード。
- src/08t_deform_v29.js: GLB読み込み時に実際のスキンを拡張し、近距離用に三角形を4分割・法線を用いた辺の平滑化・モーフ/UV/ウェイト補間。遠距離は低密度。照合率97%未満なら旧リグにフォールバック。既存CC0人体の派生モデルで、別人の新規スキャンではない。
- tools/build_player_v29.cjs: 既存のGLB、生成ウェイト、Three.jsから単体の高密度GLBを出力する。node tools/build_player_v29.cjs dist/player-v29.glb。着色用ユニフォーム素材はゲーム内で合成する方式を維持。
- 独立したCMU実測6クリップを追加（docs/MOCAP_V29.md）。2投球をオーバーの選手別フォームに選択、残りは動作検証ページで確認。バット・球の実測はなくイベント推定。
- v29 CCD: バットのアニメーション骨格とカーソル目標で姿勢を2ms間隔でサンプル、移動球対分割カプセルの連続衝突時刻、接触法線、速度、打球方向を算出。分割カプセルと実メッシュの差は残る。バント、CPU、2Dは従来式。
- v29 Live: インプレーの確定を延期し、120Hz固定ステップで野手/走者の自由移動、選手切替、捕球、送球、塁接触、帰塁、封殺、タッグ、アピールを計算してから試合状態・成績へ反映。28秒の時間制限時は安全処理を行う。既存の走塁規則をすべて完全再現するものではない。
- 実時間/直接操作/CCDは試験機能として初期OFF。試合メニューで選択可能。
## 検証
- test/nextgen_v29.cjs: 全試合CPU完走、実測クリップ、連続衝突、直接操作、ウェイト/骨格の検証。
- test/v29_browser.py: Chromium/WebGLのブラウザ回帰、スクリーンショット、FPS測定、試合進行、保存。実際のiPhone/PC GPUでの性能とは区別する。
- 実機の計測は端末とブラウザを記録し、ゲームの `V29Runtime.report()` と確認ページで測定する。
