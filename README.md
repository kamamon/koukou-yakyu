# 高校野球シミュレーション

スマホ向けの高校野球シミュレーションゲーム（1ファイルのHTML／PWA、three.js同梱）。

- プレイ: https://kamamon.github.io/koukou-yakyu/
- iPhoneでは Safari で開いて「共有」→「ホーム画面に追加」するとアプリのように遊べます（オフライン対応）。

## 試合画面（3D）
- 選手モデルは MakeHuman（CC0）の人体メッシュをベースに生成（`tools/build_player.py`）。若い男性・アジア系・やや筋肉質の体型、163本の骨を16関節に統合、手の指まで動く。目・眉・口の表情ユニットを合成した表情（集中・雄叫び・笑顔・悔しさ・歯を食いしばる・まばたき）と、選手ごとに異なる顔・肌の色
- ユニフォームは体に沿った布のシェルに、チームごとに合成したテクスチャ（ピンストライプ／前立て／袖ライン／ラグラン／胸バンド、しわの法線マップ、日焼け、汚れ。汚れはスライディングで増える）
- モデルを読み込めない環境では手続き生成モデルにフォールバック。メニューで「パワプロ風（2頭身）」にも切り替え可能
- 評価用ビューワー: https://kamamon.github.io/koukou-yakyu/viewer.html
- 投球フォーム：セット→足上げ→踏み出し→腕を担ぐ→体幹回転→リリース→フォローの7段階。オーバー／スリークォーター／サイド／アンダーの4フォーム、走者ありはセットポジション
- スイング：構え→テイクバック→踏み込み→腰の回転→インパクト→エクステンション→フォロー。両手のグリップはIKで追従
- ボールの挙動は物理計算（重力＋空気抵抗＋マグヌス力）。球種ごとの回転数・回転軸で曲がり方が決まり、打球も打球速度・角度・バックスピンから飛行（到達点はゲームの判定に一致）
- カメラ：打席（捕手の目線）／投球（センターカメラ：投手の全身とゾーン）／フィールド（ハイホーム固定ズーム）／本塁打リプレイ／攻守交代の俯瞰
- 昼・ナイター対応（ACESトーンマッピング）。WebGLが使えない端末では自動で2D表示に切り替わり、メニューから2Dに固定もできます

## 試合モード
- **采配カード**（標準）: 栄冠ナイン風。カードで指示を出し、選手の能力と信頼度で結果が決まる
- **操作モード**（上級者向け）: 打撃は「画面を押すと投球開始 → 押したまま動かしてヒットゾーンを合わせる → 離すとスイング」。投球は「ドラッグで狙い → タップで開始 → もう一度タップでリリース」の2回押し。守備は自動（設定で送球先の選択もできます）
- 中継風の演出: スコアバグ、打者／投手カード、球速表示、PERFECT/GOOD判定、本塁打のスローリプレイと飛距離表示、ラインスコア

## 構成とビルド
```
src/        ゲーム本体（連結して1ファイルにする）        tools/      選手モデル・テクスチャ生成（Python）
vendor/     three.js r152（MIT）                           tools/mh/   MakeHuman のベースメッシュ・ターゲット（CC0）
viewer/     モデルビューワー                                assets/     生成した player.glb とテクスチャ
pwa_src/    manifest・アイコン・service worker                test/       node / Playwright のテスト
```
```
pip install -r requirements.txt
python3 tools/build_player.py     # assets/player.glb
python3 tools/build_textures.py   # assets/*.png / *.jpg
bash build.sh                     # dist/pwa（この配布物）, dist/高校野球シミュレーション.html, dist/viewer.html
```
GitHub Pages には `dist/pwa` の中身をリポジトリ直下に置いています。
