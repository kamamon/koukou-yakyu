# 高校野球シミュレーション

スマホ向けの高校野球シミュレーションゲーム（1ファイルのHTML／PWA、three.js同梱）。

- プレイ: https://kamamon.github.io/koukou-yakyu/
- iPhoneでは Safari で開いて「共有」→「ホーム画面に追加」するとアプリのように遊べます（オフライン対応）。画面上部の校名の横に **v番号**（バージョン）が出ます。「その他 → 設定 → バージョン」で更新の確認と再読み込みができます
- v22 以降はステータスバーを半透明にしないようにしました（iOS 26.1 以降で上部にグラデーションのモヤが出るため）。すでにホーム画面に追加している場合は、いったん削除して追加し直すと反映されます

## 試合画面（3D）
- 選手モデルは MakeHuman（CC0）の人体メッシュをベースに生成（`tools/build_player.py`）。若い男性・アジア系・やや筋肉質の体型、163本の骨を16関節に統合、手の指まで動く。目・眉・口の表情ユニットを合成した表情（集中・雄叫び・笑顔・悔しさ・歯を食いしばる・まばたき）と、選手ごとに異なる顔・肌の色
- ユニフォームは体に沿った布のシェルに、チームごとに合成したテクスチャ（ピンストライプ／前立て／袖ライン／ラグラン／胸バンド、しわの法線マップ、日焼け、汚れ。汚れはスライディングで増える）
- モデルを読み込めない環境では手続き生成モデルにフォールバック。メニューで「パワプロ風（2頭身）」にも切り替え可能
- 評価用ビューワー: https://kamamon.github.io/koukou-yakyu/viewer.html
- 投球フォーム：セット→足上げ→踏み出し→腕を担ぐ→体幹回転→リリース→フォローの7段階。オーバー／スリークォーター／サイド／アンダーの4フォーム、走者ありはセットポジション
- スイング：構え→テイクバック→踏み込み→腰の回転→インパクト→エクステンション→フォロー。両手のグリップはIKで追従
- ボールの挙動は物理計算（重力＋空気抵抗＋マグヌス力）。球種ごとの回転数・回転軸で曲がり方が決まり、打球も打球速度・角度・バックスピンから飛行（到達点はゲームの判定に一致）
- カメラ：打席（捕手の目線）／投球（センターカメラ：投手の全身とゾーン）／フィールド（ハイホーム固定ズーム）／本塁打リプレイ／攻守交代の俯瞰
- 昼・ナイター対応（ACESトーンマッピング）。WebGLが使えない端末では自動で2D表示に切り替わり、メニューから2Dに固定もできます

## 選手の動きとプレーのつながり（v25）
- **動きの土台を作り直し**（`src/08k_ui_motion.js`）：体の動きを「時刻の関数」として計算するので、スローでもコマ送りでも同じ姿勢になります
  - 関節のキーを単調3次補間でつなぎ（キーごとに止まらない）、部位ごとに到達時刻をずらして「腰→胸→肩→腕」のしなりを作る
  - 脚は足首の目標を2関節IKで解き、接地中の足は地面に固定（マウンドの傾斜も考慮）。届かないときは腰を下げ、手足は伸ばさない
  - 走りは移動距離から着地点を先に決める（足が滑らない）。加速・減速・停止・旋回・横移動・後退、かかとの巻き上げとひざの引き上げ
  - 区間の切り替えは位置・向き・関節・足を補間し、接地している足はそのまま引き継ぐ
- **ボールの管理を1か所に**：手で保持→リリース→飛行→捕球→グラブで保持→持ち替え→手で保持、を時刻表で持つ。リリースはその時刻の手の位置から、捕球はグラブのポケットに合わせる（IK）。打球は「当たり」と判定されたときだけ、接触の時刻のボールの位置から出る（バットの芯が届くよう上体・バットの角度・手元を補正）
- **投球**：セット→始動→脚上げ→踏み出し・両手の分離→着地→骨盤→胸→腕の加速→リリース→フォロー（軸足が投手板から引きずられる）→守備の姿勢→投手板へ戻る。オーバー／スリークォーター／サイド／アンダー、左投げは鏡像
- **打撃**：構え（バットの揺れ）→投手に合わせた荷重・足上げ・ステップ→トップで待つ→スイング（接触はゲームの判定と同じ時刻）→フォロー→バットを置いて走り出す。見逃し・三振のしぐさ
- **捕手**：ミットを構え、投球の来る位置で受ける（浮いたミットは使わない）。返球を投げ、投手がグラブで受ける。盗塁では立ち上がって二塁へ
- **プレーの組み立て**（`src/08m_ui_play.js`）：エンジンの結果（アウト・セーフ・進塁）は変えずに、野球のきまりどおりに動く
  - 打球を処理する野手は打球の線に入り、右・左と足を合わせて正面で捕る→持ち替え→ステップ→送球。フライは落下点へ先回り
  - ベースカバー（左方向のゴロは二塁手、右方向は遊撃手が二塁。一塁手が捕れば投手が一塁）、カバーリング（一塁＝右翼手と捕手、二塁＝中堅手、三塁＝左翼手、本塁＝投手）、外野の安打は遊撃手か二塁手が中継に出る
  - 走者は加速して走り、次へ進むときは手前でふくらんで内側の角を踏む。一塁は駆け抜け、際どい塁では足から滑り込む。フライは帰塁・タッチアップ。アウトの走者はベンチへ、生還した走者もベンチの方へ
  - 審判4人（球審・一塁・二塁・三塁）。判定する塁へ寄ってアウト／セーフのコール、球審のストライクのコール
  - 盗塁（二塁は右打者なら二塁手・左打者なら遊撃手が入る）、けん制（頭から帰塁、悪送球）、暴投（捕手が追う・投手が本塁へ）
- **モーション確認ページ**: https://kamamon.github.io/koukou-yakyu/motion.html
  - 動作（投球・スイング・ゴロ捕球→送球・フライ捕球→送球・走り・方向転換・横移動と後退・スライディング）を選んでループ再生
  - ×1／×0.5／×0.25、一時停止、コマ送り、時刻のスライダー。正面／側面／反対側／背面／真上（ドラッグで回転）
  - 動作名と段階、骨格、接地点（緑＝接地）、手・グラブのポケット・バットの芯、ボールの状態とイベント（リリース・捕球・持ち替え・接触）
- **調整する場所**
  - 動作のキー（時刻・姿勢）：`src/08l_ui_moves.js`（投球 `MODEF.p_set`、フォーム差 `MO_FORMS`、打撃 `b_stance`／`b_pre`／`b_swing`、守備 `f_gb`／`f_fly`／`f_throw`、走者 `r_lead`／`r_slide` など）。投手のテンポは脚上げのキー（t=150〜510）、踏み出し幅は `fl` の z（t=860）
  - 走り方（速さごとの歩数・接地時間・足の上がり方・前傾・腕振り）：`MO_GAIT`、IK と接地の補正量：`MOT`（`src/08k_ui_motion.js`）
  - 打撃の接触補正の上限：`moBatPrep`（上体の前傾・バットの傾き・手元のずれ最大0.32m）
  - 反応時間・送球の速さ・走る速さと肩の強さ（能力から）：`PLX`・`plSpeed`・`plArm`（`src/08m_ui_play.js`）
- 確認用のスクリプト：`test/play_lab.py`（プレーのコマ撮り＋真上からの軌跡図）、`test/pitch_lab.py`（投球の場面のコマ撮り）、`test/motion_shots.py`（モーション確認ページの撮影）、`test/probe.py`（手・バット・ボールの位置の数値確認）

## 選手モデルを自然に（v24）
- **帽子・ヘルメットを頭の形に合わせて作り直し**（`tools/gear.py`）。頭の中心から頭皮までの距離を測って、その少し外側に布や殻の面を張るので、すき間も食い込みも出ません
  - 帽子：6枚はぎの縫い目・ステッチ・ハトメ・天ボタン、反りのあるつば（裏は濃い緑）、正面のマークは刺しゅう風（左投げ・左打ちでも字が裏返らない）
  - 打者：両耳当てが一体になったヘルメット（耳穴・つば・内側のパッド）
  - 捕手：耳当てなしのヘルメット＋マスク（金属の格子・パッド・のど当て・後ろのベルト）、体に沿ったプロテクターとレガース（骨に追従）。審判も帽子＋マスク
  - かぶり物の縁に影を入れて浮いて見えないように
- **頭と顔**：坊主頭の生え際（額・もみあげ・耳まわり・襟足）を自然に。後頭部の髪の継ぎ目、うなじと顎の黒い斑点を解消。眉を弓形に、瞳を濃い茶色に。口を開けたときの口の中を暗く
- ユニフォームの細かいノイズを弱めて、近くで見たときの毛羽立ちをなくしました
- 顔のバリエーションでは頭の大きさ・額・耳を変えないようにしました（帽子とヘルメットがぴったり合うように）

## 写真から作る顔（試作）
- Canva の画像生成で作った架空の球児の正面写真を、3Dモデルの肌テクスチャに焼き込む試み（`tools/face_photo.py`）。まず1人分（評価用ビューワーの投手）だけ
- 手順：モデルの顔を正面から描画 → 写真とモデルの両方で顔の特徴点（MediaPipe Face Mesh の468点）を取る → 薄板スプラインで対応づけ → 肌テクスチャの各画素を正面に投影して写真の色を取り、顔の範囲だけ合成。写真の陰影とテカリは平らにし、体と頭皮の色を写真に合わせ、瞳の色も写真から取る
- ビューワーの「顔」で「写真から作成（試作）」と「今の顔」を切り替えられます（「顔アップ」で寄って見られます）
```
pip install mediapipe==0.10.14 opencv-python-headless scipy   # Python 3.12 まで
python tools/face_photo.py tools/photos/face1.png skin_face1.jpg   # assets/skin_face1.jpg, assets/eye_face1.jpg
```

## 試合モード
- **采配カード**（標準）: 栄冠ナイン風。カードで指示を出し、選手の能力と信頼度で結果が決まる
- **操作モード**（上級者向け）: 打撃は「画面を押すと投球開始 → 押したまま動かしてヒットゾーンを合わせる → 離すとスイング」。投球は「ドラッグで狙い → タップで開始 → もう一度タップでリリース」の2回押し。守備は自動（設定で送球先の選択もできます）
- 中継風の演出: スコアバグ、打者／投手カード、球速表示、PERFECT/GOOD判定、本塁打のスローリプレイと飛距離表示、ラインスコア
- 試合前カットイン: 相手チームの注目投手・注目野手を、3Dの寄りカメラ（マウンド／打席）とレーダーチャート付きのカードで紹介（タップでスキップ、メニューでオフにできます）
- 能力はレーダーチャートで確認できます（選手詳細。投手は投手能力と野手能力の2枚）

## オーダー（v23）
- **決めたオーダーは自動で書き換わりません**。ケガ人が出てもオーダー（計画）はそのままで、その試合だけ代役が入り、回復すれば元に戻ります。卒業・引退でいなくなった選手の穴だけを埋め、そのときはお知らせを出します
- **投手も好きな打順に置けます**（強制9番なし）。自動編成も打撃力で並べます（打てない投手は結果的に下位になりやすい）
- **適性のない守備位置には自動で就かせません**。自動編成は本職→サブポジションの順で埋め、不慣れな位置はオーダー画面に「不慣れ」と表示。代打・代走で不慣れな位置に入ったときは、守備位置の入れ替えか守備固めで自動的に整えます
- DH制（2026年春から高校野球でも採用）を選べます。CPUの学校も7割ほどが採用
- 「自動編成」は決定を押すまで保存されません。試合タブの「自動」は確認してから上書きします

## 新聞（白球新報）
- スポーツ紙の一面のような紙面：題字・号数・天気、縦組みの大見出しと袖見出し、写真（3Dの試合中に撮った一枚、なければ似顔絵）、ラインスコア、談話、二番手記事、日程・部内成績・大会結果、コラム「球音」、広告
- **大会の開幕号**：本紙予想の優勝候補（◎○▲△）、注目選手（似顔絵・学年・最速／通算本塁打）、自校の戦力分析（投手力・攻撃力・守備力・機動力）と初戦の相手
- 甲子園出場・優勝などは**号外**。ホームに最新号の見出しが出ます。他校の注目選手の話題も毎週載ります

## 臨場感
- 場内アナウンス（打者紹介、選手交代）と実況を字幕で（設定で音声読み上げも）。試合開始・終了のサイレン、ブラスバンドと太鼓の応援（オリジナルの旋律）、歓声
- 観客の入りが大会と回戦で変わる（練習試合はまばら、甲子園の決勝は満員）
- 公式戦に勝つと**校歌斉唱**：選手がバックスクリーンを向いて整列し、スコアボードの上に校旗が上がる（校歌の歌詞と旋律は学校ごとに自動でつくるオリジナル）。甲子園で負けると**甲子園の土**
- **宿命のライバル**（県内の強豪校）との対戦成績、**思い出アルバム**（本塁打や試合終了の瞬間の写真、優勝旗・甲子園の土などの記念の品）
- 各演出はメニューの設定でオン・オフできます

## 打撃バランス
- 強打者ほど加速度的に打ち、相手投手が格下なら（ミート−被安打性の二乗で）さらに打ち込みます
- **本塁打はパワーで指数的に増えます**。S級（パワー95）のスラッガーは弱い相手に1試合1〜2本、平均的な相手にも1本前後で、毎週練習試合を組めば**年間100本塁打**も狙えます。A級（85）で年間50〜70本、B級（75）で10〜25本、平均的な選手はまれ。打球速度（150km/h超）と角度（20〜45度）から飛距離を計算し、フェンス際は確率判定
- 練習試合はコールドが「7回以降10点差」になり、最低7回は打席が回ります（公式戦は従来どおり5回10点差／7回7点差）
- 投手の疲労による能力低下を半減→最大3割強に緩和（終盤の打ち込まれすぎを抑制）
- 空は雲やモヤのない澄んだ青空に（3D／2Dとも）

## ランクと注目選手
- 総合ランク **S** は全国でも3〜5人（強豪校に所属する「全国の注目選手」）。無名のCPU選手が偶然Sになることはありません。学校の強さ **S**（90以上）も全国で3〜5校だけで、毎年4月に入れ替わります
- 「その他 → 注目選手」で全国の注目選手と強豪校の一覧を見られます。対戦すると、その選手が実際に相手のロスターに入ります

## 構成とビルド
```
src/        ゲーム本体（連結して1ファイルにする）        tools/      選手モデル・テクスチャ生成（Python）
vendor/     three.js r152（MIT）                           tools/mh/   MakeHuman のベースメッシュ・ターゲット（CC0）
viewer/     モデルビューワー                                assets/     生成した player.glb とテクスチャ
pwa_src/    manifest・アイコン・service worker                test/       node / Playwright のテスト
```
```
pip install -r requirements.txt
python3 tools/build_player.py     # assets/player.glb
python3 tools/gear.py             # assets/gear.glb（帽子・ヘルメット・マスク・プロテクター）と素材
python3 tools/build_textures.py   # assets/*.png / *.jpg
bash build.sh                     # dist/pwa（この配布物）, dist/高校野球シミュレーション.html, dist/viewer.html, dist/motion.html
```
GitHub Pages には `dist/pwa` の中身をリポジトリ直下に置いています。
